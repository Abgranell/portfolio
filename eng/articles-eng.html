PRISM: Prompt-Conditioned Imitation Skill Refinement for Manipulation

ERF - 2026
Arnau Boix-Granell, Alberto San-Miguel, Magí Dalmau-Moreno, and Néstor García
Topics: IL RL LLM HRI IsaacSim IsaacLab Python VR

Summary: This paper presents PRISM: a prompt-conditioned imitation policy refinement method for robotic manipulation. This approach integrates imitation learning (IL) and reinforcement learning (RL) into a unified workflow, allowing a generic imitation policy generated from user-guided demonstrations to be refined through reinforcement to generate new, previously unobserved detailed behaviors. The refinement process follows the Eureka paradigm, where reward functions for RL are generated iteratively from an initial natural language task description. The proposed method extends this mechanism to adapt a refined imitation policy to new target configurations and incorporate constraints via human feedback corrections during intermediate executions. This allows policy reuse and improves data-efficiency. Results on a pick-and-place task in a simulated environment show that the proposed method outperforms policies without human feedback, improving robustness during deployment and reducing computational load.

A Virtual Reality Framework for Rapid Dataset Generation Applied to Garment Manipulation with Automatic Semantic Labeling

ICRA - 2023
Júlia Borràs, Arnau Boix-Granell, Sergi Foix, and Carme Torras
Topics: VR Cloth Manipulation Matlab C++

Summary: Teaching complex manipulation skills, such as folding garments, to a dual-arm robot is a very challenging task often addressed through learning from demonstration. The few garment-folding demonstration datasets currently available to the robotics research community have either been gathered from human demonstrations or generated via simulation. The former approach presents major difficulties in perceiving both the garment state and human actions and transferring them to the robot's dynamic control, whereas the latter requires open-loop programming of human motions in the simulator without incorporating the visual feedback that humans naturally use, leading to unrealistic movements. In this paper, we present an accurate dataset of human garment-folding demonstrations. The data is gathered using our novel virtual reality (VR) framework based on the Unity 3D platform and the HTC Vive Pro system. This framework allows realistic simulation of garments and real-time interaction using handheld controllers. Thanks to the immersive experience, the system allows leveraging human visual feedback during demonstrations while avoiding the difficulties of capturing the garment state, thereby simplifying data collection and yielding more realistic demonstrations. Finally, we create and release a dataset of garment manipulation sequences, whose states are automatically and semantically labeled using a novel low-dimensional representation that clearly distinguishes different garment configurations.

Garment Manipulation Dataset for Robot Learning from Demonstration Using a Virtual Reality Framework

CCIA - 2022
Arnau Boix-Granell, Sergi Foix, and Carme Torras
Topics: VR Cloth Manipulation Unity C++

Summary: Teaching complex skills, such as folding garments, to a dual-arm robot is a very challenging task often addressed using learning from demonstration datasets. The few garment-folding datasets currently available to the robotics research community have been obtained from human demonstrations or generated via simulation. The first approach presents major difficulties in perceiving human actions and transferring them to the robot's dynamic control, while the second requires open-loop programming of human motions in the simulator, resulting in unrealistic movements. In this paper, we present a reduced yet highly accurate dataset of human garment-folding demonstrations. The data is collected using a novel virtual reality (VR) framework we propose, based on the Unity 3D platform and the HTC Vive Pro system. This framework allows garments to be simulated very realistically and interacted with in real time using handheld controllers. Thanks to the immersive experience, our framework eliminates the gap between human and robotic perception-action loops, while simplifying data collection and yielding more realistic samples.
