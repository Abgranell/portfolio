# Technical Skills Taxonomy / Taxonomia de Competències Tècniques

## English & Catalan Technical Matrix

### 1. Robotics AI & Learning / IA Robòtica i Aprenentatge
- **Vision-Language-Action (VLA) Models / Models Visió-Llenguatge-Acció:** Fine-tuning, evaluation, and physical embodiment of end-to-end multimodal manipulation policies (OpenVLA, LeRobot).
- **Agentic AI & Vision-Language Models (VLM) / IA Agèntica i Models VLM:** High-level task planning, instruction parsing, closed-loop visual reasoning, and state decomposition.
- **Reinforcement Learning (RL) / Aprenentatge per Reforç:** Deep RL (PPO, SAC), parallelized policy training in GPU-accelerated environments, prompt-conditioned reward synthesis (Eureka paradigm).
- **Imitation Learning (IL) & LfD / Aprenentatge per Imitació i LfD:** Behavior Cloning (BC), Diffusion Policies, Learning from Demonstration pipelines, human demonstration capture.
- **Sim2Real Transfer / Transferència Sim2Real:** Domain randomization (dynamics, visual, inertial), system identification, impedance adaptation, observation noise modeling.
- **Human-in-the-Loop & RLHF / Retroalimentació Humana en Bucle Tancat:** Interactive policy correction, trajectory refinement via human guidance.

### 2. Simulation & Physics Engines / Simulació i Motors de Física
- **NVIDIA Isaac Sim & Isaac Lab:** GPU-accelerated physics, multi-agent reinforcement learning, PhysX, USD scene composition, synthetic sensor rendering.
- **Unity 3D Engine:** Virtual reality physics integration, interactive cloth/deformable object simulation, custom C# scripts for sensor bridges.

### 3. Robotics Middleware & Frameworks / Middleware i Entorns Robòtics
- **ROS 2 (Robot Operating System):** Distributed nodes, lifecycle management, action servers, ros2_control, custom interfaces, QoS configuration.
- **Hugging Face LeRobot:** Physical robot data logging, dataset formatting, policy fine-tuning, and real-time inference integration.
- **MoveIt / MoveIt 2:** Motion planning, collision checking, kinematic trajectory generation.

### 4. Physical Robotic Platforms / Plataformes Robòtiques Físiques
- **PAL Robotics TIAGo PRO / TIAGo:** Mobile base, dual arms, pan-tilt head, torque-controlled manipulation, navigation and manipulation orchestration.
- **Franka Emika Panda:** 7-DOF torque-controlled collaborative manipulator, Franka Control Interface (FCI), Cartesian impedance control.

### 5. Sensors, Perception & VR / Sensòrica, Percepció i Realitat Virtual
- **Virtual Reality Systems:** HTC Vive Pro (headset, controllers, SteamVR tracking base stations).
- **Depth & Stereo Cameras:** Stereolabs ZED 2i, ZED Mini, RGB-D sensors, point-cloud acquisition, spatial tracking.
- **Hand & Body Tracking:** Leap Motion controller, optical hand kinematics, automated 3D semantic pose extraction.

### 6. Programming, Math & Engineering / Programació, Matemàtiques i Eines
- **Languages:** Python (PyTorch, NumPy, SciPy), C++, MATLAB / Simulink.
- **Version Control & DevOps:** Git, GitHub, Docker, Linux (Ubuntu).
- **Core Engineering Foundations:** Multivariable Automatic Control, Rigid-Body Dynamics, Kinematics, Linear Algebra, Optimization, Mechatronics.
